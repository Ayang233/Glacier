# R15 验收：底部弹层避开屏幕大 R 角

真机反馈：隐藏手势提示线的设备上，底部弹层最后一行会被屏幕大 R 角裁掉。
R15 给所有 `GlassBottomSheet` 的底部留白并入「手势区 ∪ 屏幕圆角」。

## 截图

| 文件 | 说明 |
|---|---|
| `01-sort-sheet-bottom-gap.png` | 应用页 · 排序弹层：卡片底边到屏幕底 117px（44.5dp） |
| `02-filter-sheet-bottom-gap.png` | 应用页 · 筛选弹层：同样 117px |

模拟器参数：1080×2400、420dpi、Android 16、宿主 GPU；圆角 28px（10.7dp）、
导航栏 inset 63px（24dp）、手势区 84px（32dp）。改动后底部留白 =
`max(24, 32, 10.7) + 12 = 44dp`，与实测 117px / 2.625 ≈ 44.6dp 吻合。

## 复现不了真机现象的原因

- 模拟器圆角只有 28px，且导航栏 inset 非 0，底部留白本来就有 36dp；
- 真机隐藏手势提示线时 `navigationBars` 底部为 0，底部留白只剩 12dp，内容落进物理圆角。

因此本轮只能证明「公式生效、无回归」，大 R 角真机的最终观感由用户侧验收。
