# Glacier 1.7.1

这一版只修预测性返回相关的两个闪烁问题，冻结后端、数据格式和外部 API 都没动，
可以直接覆盖升级。

## 关闭预测性返回后，手势返回不再闪一帧

之前关闭「预测性返回动画」只是把页面转场换成「不跟手」的版本，进程的
`enableOnBackInvokedCallback` 仍然是开启的。系统因此仍按预测性返回绘制自己的
返回窗口预览：在一级页做手势返回时，会看到整页横向偏移 + 压暗一帧，随后又弹回。

现在改为真正的系统级开关：

- 关闭时把进程内 `ApplicationInfo.enableOnBackInvokedCallback` 置为 `false`，
  系统不再下发跟手进度，也不会再画返回窗口预览；
- 页面转场始终使用 MIUIX 官方 `NavTransitions.MiuixDefault`，关闭预览后二级页
  仍然有正常的滑回动画；
- 一级页补上返回权：设置/应用页按返回先回主页，主页再返回才退出应用；
- 删除自造的 `NoPredictiveBackTransition`，不再和官方的共享 depth 驱动各算一套进度。

## 切换预测性返回开关不再闪空白

切换开关原来会 `recreate()` Activity 让标志立即生效。窗口重建期间系统只能画
`windowBackground`，实测会出现约 67ms 的整窗空白帧。

现在按官方参考实现的语义：开关只保存偏好，并提示「已保存，重启应用后生效」。
不再重建 Activity，切换时只有开关动画和 toast，没有空白帧。下次冷启动时自动应用。

## 安装

- 要求 Android 13（API 33）及以上
- `adb install Glacier-release.apk`，或直接在设备上打开
- 包名 `com.ayang.glacier`；与此前版本同签名，可直接覆盖升级
- SHA-256 见附件 `SHA256SUMS.txt`

## 已知限制

- 预测性返回开关需要重启应用后生效，设置项副标题与 toast 已明确提示。
- 锚点浮层依赖硬件 `RenderEffect`，软渲染环境（SwiftShader）不可用；玻璃光学表现
  仍需真机确认。
- 冻结真正生效依赖你选的工作模式，`default` 模式只记状态。
