1.4.0 是一次「界面底子重做 + 跟随 MIUIX 官方基线」的版本：把最后一批自定义的页面让位、
安全区与滚动条实现全部换成 MIUIX 官方契约，界面在宽屏与异形屏上不再出现背景被截断、
内容与胶囊打架的问题。冻结后端、数据格式、外部 API 与自动化逻辑未改动，可直接覆盖升级。

## 主要变化

- **宽屏布局不再"整页挪动"**：以前展开侧栏是把整个页面容器右移并缩窄，背景与顶栏的模糊带
  会跟着被裁掉一截；现在容器始终满屏，只有内容按侧栏宽度让位，侧栏下面依然是同一张背景。
  拖动侧栏展开/收起的整个过程只重新排版，不整页重绘。
- **安全区统一**：顶栏、底栏、搜索浮层、弹层、设置页与列表的刘海/横屏导航条/手势区
  全部走同一套官方 inset 契约。折叠胶囊形态下，搜索条自动落在胶囊下方；展开侧栏时
  搜索条与键盘一起右移，不再压住侧栏。
- **滚动条**：轨道起止与内容区对齐（此前会多出/少掉列表末尾的留白），顶栏收起时滚动条
  会跟着收起。
- **搜索结果**：主页与应用页改为同一份列表实现，行高、图标轮廓、包名摘要、冻结徽标的
  位置完全一致（此前主页有一份独立的手写列表）。
- **关于页**：品牌区的边距改为在排版阶段读取，转屏或侧栏展开时不再出现"先跳一下再归位"。
- **弹层动画**：MIUIX 基线升到 `44f1d315`（`v0.9.5-beta03` 之后第 18 个 main 提交），
  弹层进出动画改用官方 `DialogMotion`（对齐 HyperOS 桌面弹窗），并修复了退场尾段仍然
  吞触摸的问题。

## 安装

- 要求 Android 13（API 33）及以上
- `adb install Glacier-release.apk`，或直接在设备上打开 APK
- 包名 `com.ayang.glacier`；与此前版本使用同一签名密钥，可直接覆盖升级
- SHA-256：`38a613da61eeaafee27984d09b03332dbec36d622f252261c4a36fe1b970e53d`

## 使用前

默认 `default` 模式不会真的冻结任何应用。请先在「设置 → 通用 → 工作模式」选择设备支持的方式
（Shizuku / Root / Dhizuku / DeviceOwner / Island / 特权应用）并完成授权。
自动冻结还需要通知使用权与使用情况访问权，用来跳过正在通知或处于前台的应用。

## 已知限制

- 六种冻结后端的写操作仍需在真机验证；界面在 Android 16 模拟器（宿主 GPU）上验证。
- 玻璃的折射、边缘光等真机光学表现仍未在真实设备确认；模拟器只能证明模糊像素真实产出。
- 底部弹层（排序 / 筛选 / 操作单）本轮的底部让位改动只做了源码级核对，未逐像素实拍。
- 宽屏 + 刘海屏未实测（模拟器无刘海）；旋转/分屏过程中的中间帧未逐帧比对。
- 主题仍是固定的浅色/深色两档，未接入官方 Monet 动态取色。
