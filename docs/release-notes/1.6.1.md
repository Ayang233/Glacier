# Glacier 1.6.1

这一版把基线推到 MIUIX 最新 tag，改掉两处"自己造"的排版与动画，
并重做了主页的长按菜单和冻结按钮。

## 基线升到 v0.9.5-beta04

MIUIX 上游在 11 月 24 日重写了 main 历史（旧基线提交已不在 main 上），
所以基线从"tag + 18 个 main 提交"改成**直接对齐 tag**：`v0.9.5-beta04`。

吃到的东西：弹层动效统一到 `SheetMotion`、`DialogMotion` 精修、
按压层透明度按官方新值（20/255）并带 200ms 释放保持。Glacier 侧一行代码没改，
手感直接跟着官方走。

## 去掉了两处自造

- **「已选 N 个」不再塞进大标题。** 以前为了让中文标题和英文标题看起来一样大，
  把 `title1` 临时缩到 26.5sp，还叠了一层整条顶栏的交叉淡入淡出——那是自己造的一套排版层。
  现在大标题恒为 `Glacier`，多选进度写在官方副标题里（`已选 2 个 · 默认`）。
- **主页图标的按下层收进图标。** 以前按下时整格（含标签）变灰，现在只覆盖图标本身，
  形状还是那个 squircle。

## 冻结：一个按钮，只做冻结

右下角的按钮不再"因为这一页全冻上了就变成解冻"，也不会消失。它就是冻结，
一直待在原位：范围内没有可冻的目标时，点一下给一句「已全部冻结」。

解冻只有两个出口：

- **点开应用**：自动解冻并启动，图标随即恢复彩色；解冻失败会提示「权限不足」而不是硬启动。
- **长按应用**：菜单里的「解冻」。

冻结后图标立刻转灰度、名字转次要色，不用切页刷新（之前会因为刷新被丢弃而卡住）。

## 长按菜单按"选没选中"分两种

- 长按**已选中**的图标：批量菜单，标题是「已选择：N」，六行——
  冻结、解冻、标签分组、导出到剪切板、从主页移除、解冻并从主页移除。
- 长按**没选中**的图标（包括没进多选的时候）：还是这个应用自己的十行菜单。

也就是说长按谁，作用域里就有谁，不会出现"我长按 A，菜单却操作 B、C"。

批量动作都作用于整批：冻结/解冻跳过已处于目标状态的，导出会一次复制 N 个包名（每行一个），
标签分组换成勾选式弹层（全部带了这个标签时勾是实的，部分带是半勾）。

另外，长按之后背景图标不会再留一块按下的灰色——那层按下态以前是我们自己"按住不放"的，
现在交回组件，松手就走它自己的淡出。

## 其他

- 搜索框还没输入时，正文不再把占位文字「搜索应用」重复一遍
- 多选时如果选中的应用都冻着，点冻结会提示「所选应用已全部冻结」，而不是「已全部冻结」
- 批量打标签只刷新一次列表，不会再因为逐个写盘卡住

## 已知问题

- 长按菜单仍然是底部弹层，顶边会贴着图标那一片。官方的锚点菜单（`GlassTransformPopup`，
  从图标原地放大）已经实现过，但在没有硬件 `RenderEffect` 支持的环境（比如 SwiftShader 模拟器）
  会直接崩在渲染线程，库里没有关闭该渲染路径的开关，所以这一版没有放出来。
  真机验证通过后会切过去。
- 玻璃底栏的指示器在切页签之后，旧位置可能留一小块蓝色模糊残影。这个问题在 1.5.0 就有，
  属于 MIUIX 上游的绘制问题，用官方示例包也能复现。
- 冻结真正生效依赖你选的工作模式，`default` 模式只记状态。
