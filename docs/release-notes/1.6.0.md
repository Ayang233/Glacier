# Glacier 1.6.0

这一版主要改应用页和多选，顺手把界面里最后一点自己画的东西换成了 MIUIX 的组件。

## 应用页改成「挑应用」

点一行就是把这个应用加进主页，行尾的勾表示在不在主页，再点一次移出。加入时不弹提示，
勾出现就是反馈；移出会给一句「已将 X 移出主页」，免得误点。

应用页不再有多选，也没有「已选 N 个」。顶栏一直只有搜索、排序、筛选三个按钮。
冻结统一放在主页，应用页只管挑和看。

长按改成管理菜单：应用信息、导出到剪切板、提取安装包。弹层底部那行包名小字去掉了，
要包名用「导出到剪切板」。

卸载和重新安装去掉了。

## 主页长按出菜单

长按任意图标弹出这台应用能做的事：启动、冻结或解冻、定时任务、置顶、加入白名单、
标签分组、添加到主屏幕、导出到剪切板、从主页移除。应用已经冻结时，最后会多一行
「解冻并从主页移除」。

「添加到主屏幕」走系统的固定快捷方式，第一次会弹系统确认框。

## 多选

顶栏「多选」进来，大标题从「Glacier」变成「已选 N 个」，副标题和标签行都不动。
点图标勾选，右下角 FAB 只处理选中的那几个，一个都没选就还是整页。

标题切换用的是库里的淡入淡出曲线（`GlassMotion` 的 fade token），字号也按字形高度对齐过，
进出多选时下面的图标不会跳。再点一次「多选」或者按返回就退出。

## 其他

- 勾选状态换成官方 `Checkbox`，去掉自绘的图标蓝色描边
- 主页图标在菜单打开期间保持按下态，用的是官方的 `HoldDownInteraction`
- 批量冻结失败时不再清空选区，选好的人不用重新挑

## 已知问题

- 玻璃底栏的指示器在切页签之后，旧位置可能留一小块蓝色模糊残影。这个问题在 1.5.0 就有，
  属于 MIUIX 上游的绘制问题，用官方示例包也能复现。
- 冻结真正生效依赖你选的工作模式，`default` 模式只记状态。
