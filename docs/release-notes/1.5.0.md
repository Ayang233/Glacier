1.5.0 是交互和间距的版本：底栏改成和 MIUIX 官方一样的归属，应用页的点按/长按换了语义，
横屏展开侧栏时内容不再贴着面板。冻结后端、数据格式和外部 API 都没动，可以直接覆盖升级。

## 主要变化

- **二级页不再有底栏**。以前进「关于」时底栏会缩到 0.6 倍再弹回来，现在是底栏跟着一级页
  一起转场走掉，二级页里没有它，返回时跟着页面滑回来。这不是新写的动画，是把底栏从外壳挪进
  一级目的地（MIUIX 官方示例的 `Home()` 就是这么放的），顺便去掉了库的 `visible` 参数。

- **应用页：点按 = 选中，长按 = 操作单**。以前点一行会直接弹操作单。现在点一下就选中该应用
  （图标画上选中环，顶栏换成冻结/解冻/更多/关闭，标题变「已选 N 项」），要单独操作某个应用
  才长按。长按期间那一行保持按下态，弹层退场后才松开。搜索结果里的行是一套语义。

- **顶栏动作切换不再硬跳**。从普通态切到多选态时，两排按钮交叉淡入淡出、宽度跟着弹簧推挤，
  曲线用的是 MIUIX 自己的 `GlassMotion`（`barExpand` / `barCollapse` / `scaleIn` / `scaleOut`）。
  同一批还有两个小地方：进多选时 FAB 是缩着淡出，页签行是收起来，而不是凭空消失。

- **多选时按返回先退出多选**。应用页现在点一下就进多选，没有这条退路的话，点错一行按返回
  就直接退出应用了。

- **横屏侧栏和内容的间距**。页面 12dp 留白以前是塞进 `max(安全区, 侧栏让位, 12dp)` 里算的，
  侧栏展开到 262dp 时那 12dp 被吃掉，卡片就贴住了玻璃面板。官方是「让位 + 卡片自身 12dp」，
  现在改成相加，并修掉了一处写错方向判断导致的「左边有、右边没有」。

- **宽屏断点读窗口尺寸**。以前用屏幕宽度判断是否宽屏，分屏、自由窗口下会把窄窗口当成宽屏。
  改成官方 `AdaptiveUtils` 用的 `LocalWindowInfo.containerSize`，断点数值没变（840 / 600+1.2 / 1200）。

## 安装

- 要求 Android 13（API 33）及以上
- `adb install Glacier-release.apk`，或直接在设备上打开
- 包名 `com.ayang.glacier`；与此前版本同签名，可直接覆盖升级
- SHA-256 见下方 Release 附件 `SHA256SUMS.txt`，或安装后核对 APK

## 使用前

`default` 模式不会真的冻结任何应用。先在「设置 → 通用 → 工作模式」选设备支持的方式
（Shizuku / Root / Dhizuku / DeviceOwner / Island / 特权应用）并完成授权。
自动冻结还需要通知使用权与使用情况访问权，用来跳过正在通知或处于前台的应用。

## 已知限制

- 六种冻结后端的写操作仍需真机验证；界面是在 Android 16 模拟器（宿主 GPU）上验的。
- 玻璃的折射、边缘光这些光学表现没在真机上看过，模拟器只能证明模糊是真的算出来的。
- 底栏玻璃指示器切页签后偶尔在旧位置留一块蓝色残影，1.4.0 就有，属 MIUIX 上游问题，本轮没动。
- 宽屏只验了 914dp（折叠胶囊手动展开）和 1333dp（自动展开）两档；真机平板、折叠屏未测。
- 横屏 + 刘海未逐像素比过（模拟器没有刘海）。
- 主题还是固定浅色/深色两档，没接 Monet 取色。

## 工程

- 底栏从 `GlacierShell` 的 `Scaffold.bottomBar` 挪进 `entry<Route.Main>`，采样页内 `pageBackdrop`
  （原来采宿主那层会构成自采样）。
- `AppListCardRow` 的手势交给官方 `Card(onClick, onLongPress, holdDownState, showIndication)`，
  行内 `BasicComponent` 不再注册点击；`reportFreezeBatch` 抽到 `feature/common` 供主页与应用页共用。
- `pageContentPadding` 的横向留白改成相加，左右两侧都加；`isWideLayout()` / `isExtraWideLayout()`
  改读窗口尺寸；侧栏 inset 改成官方「宿主给、组件不再算一次」的写法。
- 审计与逐张验收：`docs/audit/miuix-os4-r7-audit.md`、`docs/audit/miuix-os4-r8-audit.md`，
  截图在 `docs/verification/miuix-os4-r7/`、`docs/verification/miuix-os4-r8/`。
