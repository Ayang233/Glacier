# Glacier 1.7.2

这一版只修关于页的上下滑，以及关闭玻璃后顶栏的一条透明缝；冻结后端、数据格式和外部 API 都没动，
可以直接覆盖升级。

## 关于页上下滑对齐 MIUIX

之前关于页的弹性 overscroll 挂在整个页面 wrapper 上，下拉时动态背景和品牌区会一起位移，
顶栏下面露出宿主底色；而且正文不足一屏时列表根本不能滚，上拖只会走 overscroll，
品牌不淡出、顶栏标题不出现，卡片会压到品牌上。

现在按 MIUIX 官方 `AboutPage` 的结构重排：

- `pageScrollModifiers` 挂到 `LazyColumn` 本身，背景和品牌区固定；
- 正文卡片收进同一个 item，用 `Spacer(fillParentMaxHeight())` 撑到至少一屏，
  列表可以真实滚动，品牌淡出与顶栏标题重新由滚动进度驱动；
- 下拉/上拖回弹时只有列表内容移动，不再露白、不再压字。

## 关闭玻璃后，上滑不再从状态栏透内容

非玻璃顶栏原来让 `TopAppBar` 把底色画在 `appPageTopBarInsets()` 里面，状态栏那一条
没有任何覆盖，列表滚到下面就透出来。

现在照 MIUIX 官方 `AdaptiveTopAppBar` 的非玻璃分支：底色挂在外层
`Modifier.background(surface)`，`TopAppBar` 自身传 `Color.Transparent`。这是所有非玻璃
页面共用的修复，设置页、主页等也不会再从状态栏透内容。

## 安装

- 要求 Android 13（API 33）及以上
- `adb install Glacier-release.apk`，或直接在设备上打开
- 包名 `com.ayang.glacier`；与此前版本同签名，可直接覆盖升级
- SHA-256 见附件 `SHA256SUMS.txt`

## 已知限制

- 关于页列表为了对齐官方结构，滚到底后会保留一屏空白（官方同样如此），用于让品牌完整淡出。
- 锚点浮层依赖硬件 `RenderEffect`，软渲染环境（SwiftShader）不可用；玻璃光学表现
  仍需真机确认。
- 冻结真正生效依赖你选的工作模式，`default` 模式只记状态。
