# Glacier 1.7.0

## MIUIX 基线升到最新 main

`542463a0`（`v0.9.5-rc01`）→ `e7c108ee`（官方 main 最新）。这 10 个提交集中在 Glass：
`GlassTopAppBar` 渐进模糊带重写、`GlassBottomSheet` 默认改为非覆盖式标题栏、新增
`GlassScrollableTabRow`、AGP 9.5.3。Glacier 侧同步 AGP，并把 6 个底部弹层显式切回
官方 demo 的覆盖式模糊标题栏；主页标签超过 4 个时改用官方横向滚动页签。

## 自造轮子复查与替换

再次全项目扫描 UI / 动画 / 尺寸 / 间距 / 边距：没有自建玻璃、模糊、阴影、按压、选中态
或自建弹层 / 导航 / 滚动条；本轮把「非玻璃档顶栏图标 28dp」「弹层标题 8dp」
「对话框 16dp」「关于页标题淡入曲线」等与官方默认不一致处收敛到官方值。

## 冻结应用点按秒开

之前点开已冻结应用会先解冻、再等一次全量应用枚举（约 500ms）才启动。现在解冻成功后
立即 `startActivity`，列表刷新改到后台串行执行；Island 模式仍等系统可启动后再拉起。
用 `adb logcat -s GlacierLaunch` 可以看到启动发生在刷新之前。

## 应用页不再重复提示「不在主页」

行尾勾选框已经表达「在主页 / 不在主页」，副标题里那段「· 不在主页」删除。

## 关于页更干净

去掉「应用 / 系统 / 开源信息」三个小标题；版本号只在品牌区出现一次；包名与构建类型
合成一行；开源许可证只保留可点击入口（行尾 SPDX），不再重复两行说明。

## 预测性返回重做

照 InstallerX-Revived 的做法：

- manifest 常开 `enableOnBackInvokedCallback`，系统始终派发返回进度；
- 设置只切 `NavDisplay` 的 `predictivePop` 转场：开启时用官方 `MiuixDefault` 跟手，
  关闭时页面不跟手位移、松手仍播 pop；
- 删除 `HiddenApiBypass` + 反射 + `recreate()`：开关即时生效，不再重建 Activity，
  也就不会再出现切换时的一帧闪烁。

之前的「不跟手」来自旧实例持久化里开关是关闭状态；现在默认开启，并且不再依赖
隐藏 API 豁免是否成功。
