# Glacier 1.0.0

首个公开版本。一个独立的 Android 应用冻结工具，界面完全建立在 MIUIX OS4 与官方 Glass 之上。

## 这次包含什么

**页面**：Home（标签 / 应用网格 / 多选 / Glass 搜索 / FAB）、Apps（列表 / 排序 / 筛选 / 操作单）、
Settings（官方 Preference + 玻璃下拉）、About、开源许可证、以及独立窗口的 API 入口。

**冻结后端**（工作模式可切换）：
Shizuku（force stop / 禁用 / 隐藏 / 挂起）· Root · Dhizuku · DeviceOwner · Island · 特权应用。

**自动化**：锁屏后自动冻结（WorkManager + 前台服务 + 通知监听）、延迟冻结、
"充电时跳过 / 跳过前台应用 / 跳过有通知的应用"、快捷设置磁贴、桌面快捷方式。

**外部 API**：11 个 Intent Action 与 `glacier://` 深链，
包括 `LAUNCH` / `FREEZE` / `UNFREEZE` / `FREEZE_TAG` / `FREEZE_ALL` / `LOCK_FREEZE` 等。

**界面体系**：唯一主题入口 `MiuixTheme`，颜色与字号全部来自官方主题；
玻璃只用在"浮在内容之上"的位置（顶栏、导航胶囊、侧栏、FAB、弹层、搜索），
设置页与列表项保持普通 MIUIX 组件。

## 安装

- 要求 Android 13（API 33）及以上
- `adb install Glacier-release.apk`，或直接在设备上打开 APK

## 必须知道的限制

1. **冻结需要设备侧权限。** 装上后默认是 `default` 模式，此时不会真的冻结任何应用。
   请先在设置里选一个本机支持的后端：装 Shizuku 并授权、或有 root、或被设为 DeviceOwner、
   或装有 Island 并授予对应权限。缺少权限时界面会如实提示"权限不足"，不会假装成功。
2. **本版本未在真机验证冻结链路。** UI、导航、玻璃结构在 Android 16 模拟器上逐页验证过；
   六条后端的写操作只有源码级实现，没有真机运行证据。请把它当作 1.0 试用版。
3. **玻璃的光学观感未验证。** 模拟器是软件渲染，AGSL 与真实模糊不可信；
   真机上的折射、模糊、边缘光需要你自己看。
4. 少数交互（通知使用权、使用情况访问、生物识别）需要在系统设置里手动授权后才生效。
