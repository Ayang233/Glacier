# Glacier 1.6.2

这一版把长按菜单从「底部弹层」换成官方的「锚点浮层」（`GlassTransformPopup`），
基线跟到 MIUIX main 最新，并收掉了浮层宽度、首次长按动画、横屏遮挡侧栏这三处问题。
冻结后端、数据格式和外部 API 都没动，可以直接覆盖升级。

## 长按菜单：从图标原地展开

以前长按是底部升起一张弹层，顶边会贴着图标那一片；现在是官方的锚点浮层，
**从被长按的那一格（主页图标 / 应用页行）原地放大展开**，关闭时按官方回弹曲线复位。

浮层经官方 example 的 `TopLayer` 提升到根部，因此：

- 不会被宽屏侧栏盖住，也不会采到自己的背景（玻璃的三条采样规矩都满足）；
- 不再另开窗口，长按松手的 UP 事件不会被吞；
- 菜单打开期间锚点内容由官方 `glassPopupAnchor` 隐藏，关闭后复位，不留按下灰块。

**宽度交回官方**。官方契约是 `GlassPopupDefaults.MinWidth = 200dp`、`MaxWidth = 288dp`，
面板宽度由内容固有尺寸决定。上一版为绕开高度探测给标题行写死了 320dp（应用页 280dp），
实际会把面板顶到 288dp 上限，显得又宽又空；这一版删掉写死宽度，实测回到 200dp，
文案完整、无省略。

**首次长按也有动画**。官方要求浮层常驻组合、只用 `show` 控制开合（不要用 `if (show)` 包住调用）——
否则第一次组合时入场动画已经「播完」了。这一版改成常驻组合，并用列表首项预热菜单内容；
预热是必须的：上游 `GlassPopupSurface` 的固有尺寸缓存以内容 lambda 为 token，
如果首帧量的是空菜单，面板高度会被记成一条细条。

**横屏展开侧栏时自动让位**。官方没有「识别侧栏」的专用 API，自动让位来自浮层的摆放规则：
面板被夹在弹层宿主边界 + `safeMargin`（12dp）以内，垂直空间不足时自动翻到锚点上方。
Glacier 侧把 `TopLayerHost` 按侧栏让位宽度在布局期内缩，浮层就停在侧栏右侧，
侧栏标签保持完整可见。

## 设置项

- 工作模式的四条文案「禁用」改成「停用」（Shizuku / Root / 越狱 / 特权应用）。
- 外观组里「主页标签字号」与「合成自适应图标」两项对调了位置（字号在前、开关在后）。

## 基线：MIUIX main `542463a0`

当前基线钉在官方 main 最新提交 `542463a0`（比最新 tag `v0.9.5-beta04` 多 12 个 Glass 修复），
`LIBRARY_VERSION` 仍是 `0.9.5`，Compose / Kotlin / AGP 未变。吃到的东西：

- 锚点浮层关闭回弹、`GlassBottomSheet` 渐进模糊标题栏、`GlassTopAppBar` 模糊带与动态色对比度修复；
- 关于页信息卡换成官方 `GlassCard`，去掉自绘的模糊+混色 token；
- 6 处 `GlassBottomSheet` 按新签名（内容槽给 `PaddingValues`）重接；
- 列表页统一用官方的滚动契约（`overscrollEffect = null` + 官方 `pageScrollModifiers`），
  横向内边距改用 `GlassTopAppBarDefaults.HorizontalPadding`。

## 安装

- 要求 Android 13（API 33）及以上
- `adb install Glacier-release.apk`，或直接在设备上打开
- 包名 `com.ayang.glacier`；与此前版本同签名，可直接覆盖升级
- SHA-256 见附件 `SHA256SUMS.txt`

## 已知限制

- **长按菜单超过 6 行会在弹层内滚动**：上游 `GlassPopupColumn.POPUP_PROBE_COUNT = 8`
  只探测标题 + 分割线 + 前 6 行，主页 10 行菜单需要滑动才能看到最后几行；这是库的限制，没有改库。
- **锚点浮层依赖硬件 `RenderEffect`**：软渲染环境（如 SwiftShader 模拟器）会崩在渲染线程，
  库里没有关闭该渲染路径的开关。本轮在接宿主 GPU 的模拟器（Android 16 / API 36）上验证，
  真机玻璃光学（折射、边缘光）仍需真机确认。
- 玻璃底栏指示器切页签后偶有残影，属 MIUIX 上游绘制问题，官方示例包同样可复现。
- 冻结真正生效依赖你选的工作模式，`default` 模式只记状态。
