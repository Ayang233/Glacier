1.3.0 是一次「跟随 MIUIX 官方基线」的升级版本：把界面依赖从 MIUIX `58b0a3dd` 升到官方
`v0.9.5-beta02`（`66248bac`），并按新版 API 重做了三处界面行为。冻结后端、数据格式、
外部 API 与自动化逻辑均未改动，可直接覆盖升级。

## 主要变化

- **顶栏模糊**：恢复 MIUIX 官方的渐进模糊管线。此前在模拟器/部分环境会被主动关掉（
  顶栏只剩纯色带），现在统一走官方能力：内容滚到顶栏下面时出现渐进模糊，滚动越界时
  材质跟着动。搜索浮层的缩放+模糊转场同样恢复。
- **文本输入**：新建/重命名标签的输入框换成官方 `GlassTextField`（玻璃对话框专用），
  聚焦描边、浮动标签、保存按钮的可用状态都跟随输入实时更新；底层迁移到新的
  `TextFieldState` API（旧的 `value/onValueChange` 已被 MIUIX 废弃）。
- **宽屏二级页标题**：折叠成顶部胶囊后，关于/许可证页的标题不再整条消失，而是按官方
  `centerObstructionStart` 让位到胶囊右侧；一级页仍按官方语义随侧栏淡出。
- **依赖基线**：MIUIX `v0.9.5-beta02`（`LIBRARY_VERSION 0.9.5`）、Compose 1.13.0
  （BOM `2026.11.01`）。滚动条触摸目标随官方收到 24dp，标签与列表的按压区不变。
- **工程**：新增 `MIUIX_BASELINE.md`（基线、定制边界、升级流程）与
  `tools/miuix-baseline.sh`（status / fetch / pin / verify），补上搜索键的 5 个单元测试。

## 安装

- 要求 Android 13（API 33）及以上
- `adb install Glacier-release.apk`，或直接在设备上打开 APK
- 包名 `com.ayang.glacier`；与此前版本使用同一签名密钥，可直接覆盖升级
- SHA-256：`bee840fdcd6109470ddc847e84c6e66be0216208acf9b482cbc5b6cb2f8075eb`

## 使用前

默认 `default` 模式不会真的冻结任何应用。请先在「设置 → 通用 → 工作模式」选择设备支持的方式
（Shizuku / Root / Dhizuku / DeviceOwner / Island / 特权应用）并完成授权。
自动冻结还需要通知使用权与使用情况访问权，用来跳过正在通知或处于前台的应用。

## 已知限制

- 六种冻结后端的写操作仍需在真机验证；界面在 Android 16 模拟器（宿主 GPU）上验证。
- 玻璃的折射、边缘光等真机光学表现仍未在真实设备确认；模拟器只能证明模糊像素真实产出。
- 宽屏 + 刘海屏的顶栏缩进本轮按官方语义修正，模拟器无刘海，未实测。
- 主题仍是固定的浅色/深色两档，未接入官方 Monet 动态取色。
- 尚未完成：应用列表多选、分屏/自由窗口断点、RTL、三键导航的逐项验证。
