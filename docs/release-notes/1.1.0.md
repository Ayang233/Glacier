# Glacier 1.1.0

第二轮界面整改：把整个应用按 MIUIX OS4 / OS4 Glass 重新对齐。这一版仍然只有界面与交互层面的改动，
冻结后端、数据格式、外部 API 与自动化逻辑与 1.0.0 完全一致，可覆盖升级。

## 这次修正了什么

**底部导航（1.0.0 最明显的问题）**
- 玻璃导航胶囊不再整屏拉满，改为 MIUIX 官方示例的 `24dp` 横向内边距（411dp 屏实测胶囊 363dp）；
- 底栏进入页面 `Scaffold.bottomBar`，正文与 FAB 的让位由 Scaffold 按**实测**胶囊高度计算，
  删掉了手算的 `Height + 导航栏 + 32dp` 魔法值（此前页面底部多留 68~104dp）。

**页面骨架与间距**
- 页面留白 / 卡片间距 / 列表末尾统一为官方 12dp，清掉 6/8/16/18dp 混用；
- 修复 `pageContentPadding` 缓存第一帧 PaddingValues 的问题（Home 网格曾永远按错误的顶栏高度起排，标签会压住图标）；
- 修复分页器在动画中回写 `currentPage` 导致 spring 被取消、出现"两页各露一半"的竞态；
- 空状态正确让出顶栏；页面切换使用官方 `PagerNavigationSpringSpec`。

**宽屏**
- 对齐官方自适应：≥1200dp 常驻展开玻璃侧栏，840–1200dp 折叠为顶部胶囊（可点开展开）；
- 侧栏展开时顶栏标题按 morph 进度淡出，搜索浮层让开折叠胶囊；二级页不再沿用一级页的侧栏高亮。

**搜索 × 交互 BUG**
- 搜索浮层改为常驻组合（只由 `expanded` 驱动），保留官方 400ms 几何动画与 150ms 取消按钮动画；
- 输入框内 × 只清空输入、右侧 × 只关闭搜索；点关闭后不会打开标签编辑（已按 8 步流程实测）；
- 搜索结果行改用官方卡片 + 标准行组件，底部为悬浮底栏让位。

**弹层与动画**
- Dialog / BottomSheet / 下拉菜单全部改为"常驻组合 + `show`"，退出动画不再被 `if` 砍掉；
  标签编辑、标签命名、删除确认、延时冻结、排序、筛选、操作面板、API 窗口错误弹层均覆盖。

**About 页**
- 按 MIUIX 官方 About 示例重写：88dp 白底品牌区（24dp 圆角）、74dp 黑色标记、35sp Bold 应用名、
  14sp 版本、官方卡片分组与 12dp 间距，二级页顶栏不可展开。

**图标**
- 自适应图标按 Android 规范的 72dp 安全区 1.5× 渲染后再套 MIUIX squircle 轮廓
  （此前按 108dp 画布直接铺，第三方图标只显示约 2/3 大）；
- 品牌图标改为白底 + 黑色主体、无渐变；Home 网格与 Apps 列表共用同一图标组件与圆角比例。

**排版**
- 硬编码英文与字符串拼接全部资源化；About/Licenses/Settings 的标题、值、说明走统一排版层级。

## 必须知道的限制

1. **冻结需要设备侧权限。** 默认 `default` 模式不会真的冻结任何应用；请在设置里选择本机支持的后端
   （Shizuku / Root / Dhizuku / DeviceOwner / Island / 特权应用）。缺少权限时会如实提示"权限不足"。
2. **本版本仍未在真机验证冻结链路。** 六条后端的写操作只有源码级实现；UI 与导航在 Android 16 模拟器上验证。
3. **玻璃的光学观感（L3）未验证。** 模拟器为软件渲染（`ro.hardware.egl = emulation`），
   折射、模糊半径、边缘光请在真机自行确认；本版本可以确认的是玻璃组件的挂载、采样与交互（L2）。
4. 部分交互（通知使用权、使用情况访问、生物识别）需要在系统设置里手动授权后才生效。
5. 已知未完成项：About 的 logo 滚动淡出动画、页面 overscroll/滚动条修饰、二级页转场特效、
   Apps 多选、RTL / 三键导航 / 弹层大字体未逐项验证。完整清单见审计报告第 17.5 节。

## 安装

- 要求 Android 13（API 33）及以上
- `adb install Glacier-release.apk`，或直接在设备上打开 APK
- 包名 `com.ayang.glacier`；1.0.0 可直接覆盖升级
