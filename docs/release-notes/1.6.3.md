# Glacier 1.6.3

这一版是「弹层安全区 + 设置页重构 + 品牌图标 + 冷启动」的收尾版本。冻结后端、数据格式和
外部 API 都没动，可以直接覆盖升级。

## 底部弹层不再被屏幕大 R 角裁掉

排序 / 筛选 / 标签分组 / 延时冻结 / 应用操作单这些底部弹层，底部留白现在取
`max(安全区底部, 手势区底部, 屏幕圆角) + 分节间距`。

原因是隐藏手势提示线后 `navigationBars` 底部 inset 会变成 0，旧写法只剩 12dp 分节间距，
内容正好落进屏幕物理圆角的裁剪区；圆角又不属于任何 `WindowInsets`，MIUIX 只提供
`getRoundedCorner()` 原语、弹层底部安全区按官方契约本来就由调用方给。现在两者都并进去了，
模拟器实测底部留白 36dp → 44dp，真机上最后一行回到圆角之外。

## 设置页重排：一级入口 + 二级归类

- **去掉所有分节小标题**，设置首页不再是一长串「通用 / 外观 / 搜索…」；
- 首页只留：通用（工作模式、启动时验证）+ 四个入口（主题设置 / 搜索 / 自动化 / 系统）+ 关于；
- 外观改名「主题设置」并移到二级页，原来的外观设置项全在那一页；
- 四个二级页统一是官方二级页结构：返回按钮、不折叠大标题、边缘滑动返回、没有底栏。

## 新增：预测性返回动画开关

Android 14+ 可在「主题设置」里开关系统返回手势的跟手预览。关掉它**不等于关掉返回动画**：
返回手势仍会触发、页面照常播放 MIUIX `NavDisplay` 的 pop 转场，只是不再有拖动过程中的预览。
实现照官方 MIUIX example 的做法（改 `enableOnBackInvokedCallback` 进程标志 + 重建 Activity）。

## 新增：隐藏应用名称

「主题设置」里可以只显示主页图标。隐藏的是名称文字本身，**布局不重排**：标签仍占原来的行高，
网格行距、图文间距、列宽公式都没变，图标位置不会跳；读屏仍能念出应用名。

## 品牌图标与冻结按钮

- 品牌图标改成**六向完全对称**的雪花（旧版手描分叉角度不一致），黑主体白底，主体整体略缩小；
  启动器图标、关于页品牌图、快捷设置磁贴同源；
- 主页右下角的冻结按钮从「水波纹」换成雪花图标，并按官方 24dp 图标的占比放大
  （占 FAB 直径 37%，与官方图标比例一致）。

## 冷启动首帧就有主页应用

以前冷启动会先渲染一帧「0 个应用 / 主页还没有应用」，半秒后才闪回列表。现在启动时先用磁盘上的
主页列表预热一份快照（只读列表文件 + 几项包信息，不查冻结状态），首帧直接显示已加入主页的应用，
完整快照（全部应用 + 冻结态）随后补齐。

## 安装

- 要求 Android 13（API 33）及以上
- `adb install Glacier-release.apk`，或直接在设备上打开
- 包名 `com.ayang.glacier`；与此前版本同签名，可直接覆盖升级
- SHA-256 见附件 `SHA256SUMS.txt`

## 已知限制

- 长按菜单标题 + 分割线后超过 6 行会在弹层内滚动（上游 `POPUP_PROBE_COUNT = 8`）。
- 锚点浮层依赖硬件 `RenderEffect`，软渲染环境（SwiftShader）不可用；玻璃光学表现仍需真机确认。
- 预测性返回开关在 OEM 手势导航上的实际观感建议真机确认（模拟器是 AOSP 手势）。
- 应用页的「全部应用」列表仍由启动刷新填充；通常切过去时已就绪。
- 冻结真正生效依赖你选的工作模式，`default` 模式只记状态。
