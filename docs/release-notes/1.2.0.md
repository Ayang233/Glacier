1.2.0 是界面与交互收口版本。冻结后端、数据格式、外部 API 与自动化逻辑与 1.1.0 一致，可直接覆盖升级。

## 主要变化

- **主页**：长按照压应用图标时的方形灰块改为与图标轮廓一致的圆角；标签栏改用 MIUIX 官方的页面级标签
  （玻璃档为分段胶囊，非玻璃档为描边胶囊），选中项不再是实心黑色胶囊。
- **关于页**：品牌图标、应用名、版本号随页面滚动错峰淡出并轻微缩放，顶栏标题随滚动淡入；回到顶部后完整复原。
- **滚动与转场**：补上官方 overscroll 弹性、滚动结束触觉与滚动条；二级页使用系统圆角裁剪加遮罩的官方转场，支持滑动返回。
- **列表与弹层**：应用列表行、搜索结果行、排序/筛选行统一为官方行组件；按压反馈只有一层；
  操作面板、排序与筛选弹层在大字体下可滚动。
- **设置页**：依赖「自动冻结」的选项在关闭时隐藏；缺少通知使用权或使用情况访问权时，对应开关直接禁用并说明原因。
- **外部 API 窗口**：窗口改为不透明，弹层背景与页面一致；解析期间显示加载态；错误信息不再输出堆栈。
- **图标**：主页、应用列表、搜索结果使用同一个图标组件与圆角；选中环出现时图标不再缩小跳动；
  第三方图标包按目标尺寸解码，避免高分辨率图标造成的内存占用。
- **文案**：精简界面内的重复说明与生硬表达；README 补充安装与首次使用说明。

## 安装

- 要求 Android 13（API 33）及以上
- `adb install Glacier-release.apk`，或直接在设备上打开 APK
- 包名 `com.ayang.glacier`；与此前版本使用同一签名密钥，可直接覆盖升级
- SHA-256：`66fea1c43d30fa0232b099cf6ce5151049fe4348c279ca75d2c28e5fa7b307b1`

## 使用前

默认 `default` 模式不会真的冻结任何应用。请先在「设置 → 通用 → 工作模式」选择设备支持的方式
（Shizuku / Root / Dhizuku / DeviceOwner / Island / 特权应用）并完成授权。
自动冻结还需要通知使用权与使用情况访问权，用来跳过正在通知或处于前台的应用。

## 已知限制

- 六种冻结后端的写操作仍需在真机验证；界面与交互在 Android 16 模拟器上验证。
- 玻璃的折射、模糊等光学效果未在真机确认（模拟器为软件渲染）。
- 通知使用权、使用情况访问权、生物识别需要先在系统设置中手动授权才会生效。
- 尚未完成：应用列表多选；分屏/自由窗口断点、刘海横屏下的顶栏缩进、RTL、三键导航未逐项验证。
